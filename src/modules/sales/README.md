# modules/sales

Órdenes de venta.

## Responsabilidad

- Creación y gestión de órdenes de venta a clientes.
- Reserva y descuento de stock al confirmar una venta.
- Estados de la orden: pendiente, en proceso, enviada, entregada.
- Correos de pedidos (REQ-104): lista los correos que registra n8n y deja ingresar a mano como OV los que el workflow descartó (`/ventas/correos`).
